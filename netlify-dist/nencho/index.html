書類の書き方

会社から配られる書類は主に4種類です。
タブを切り替えて、見ながら書き進めてください。

令和8年分 給与所得者の基礎控除申告書 兼 配偶者控除等申告書 兼 特定親族特別控除申告書 兼 所得金額調整控除申告書

誰が 全員(基礎控除は必ず)添付 不要今年の注意 様式が新しくなりました

  1. あなたの給与所得金額今年1年間の給与と賞与の見込み総額から、書類の計算表で所得金額を出して書きます。
    下の自動計算に年収を入れると、同じ数字が出ます。
  2. 合計所得金額の見積額給与以外の所得がなければ、上の所得金額がそのまま入ります。
    この金額で基礎控除の額が決まります。
    489万円以下なら104万円、489万円超655万円以下なら67万円、655万円超2,350万円以下なら62万円です。
  3. 配偶者の欄配偶者の氏名と、今年の収入(または所得)の見込みを書きます。
    配偶者の合計所得が62万円以下(給与だけなら年収136万円以下)なら配偶者控除、62万円超133万円以下なら配偶者特別控除です。
    あなたの所得が1,000万円を超えると、どちらも受けられません。
  4. 特定親族特別控除の欄19歳以上23歳未満で、所得が62万円超123万円以下の子などがいる場合に書きます。
    大学生のアルバイトで年収136万円を超えた場合が典型です。
    所得に応じて63万円から3万円まで段階的に控除されます。
  5. 所得金額調整控除の欄年収が850万円を超え、23歳未満の扶養親族か、特別障害者の家族がいる人だけが書きます。

提出時期の注意 今回の様式は、令和8年12月に行う年末調整用です(様式の右上に「令和8年12月年末調整用」と書かれています)。
それより前に年末調整をする会社では様式が違うことがあるので、会社の案内に従ってください。

令和8年分 給与所得者の保険料控除申告書

誰が 保険や年金を自分で払った人添付 控除証明書(はがきまたは電子データ)

  1. 生命保険料控除控除証明書を見ながら、一般・介護医療・個人年金の3つの欄に分けて書きます。
    2012年1月1日以後に結んだ契約は「新」、それより前は「旧」です。
    金額は今年払った保険料から、配当金を引いた額です。
  2. 23歳未満の扶養親族がいる人令和8・9年分は、一般生命保険料(新契約)の控除の上限が4万円から6万円に上がります。
    該当する人は申告書の指示に従って記入します。
    生命保険料控除の合計の上限は12万円のままです。
  3. 地震保険料控除地震保険料は最高5万円まで控除されます。
    火災保険だけの分は対象外です。
  4. 社会保険料控除給与から天引きされた分は、会社が把握しているので書きません。
    自分で払った国民年金や国民健康保険(生計が同じ家族の分を含む)だけを書き、証明書を付けます。
  5. 小規模企業共済等掛金控除iDeCo(個人型確定拠出年金)や小規模企業共済の掛金です。
    払込証明書の金額を全額書きます。

令和8年分 給与所得者の扶養控除等(異動)申告書

誰が 全員(会社を主たる勤務先にする人)使い道 年末調整の扶養控除と、毎月の源泉徴収

  1. 氏名・住所・個人番号勤務先に提出済みの個人番号から変わりがなければ、その旨の記入で済む会社が多いです。
    会社の案内を確認してください。
  2. 源泉控除対象配偶者(Aの欄)配偶者の所得の見積額が要件内の場合に書きます。
    判定の表は会社が配る案内に載っているので、それに合わせます。
  3. 源泉控除対象親族(Bの欄)16歳以上の家族のうち、所得が62万円以下(給与だけなら年収136万円以下)の人を書きます。
    19〜22歳で所得が62万円を超える人は「特定親族」の欄にチェックします。
    70歳以上は老人扶養親族のチェック欄です。
  4. 16歳未満の扶養親族(住民税の欄)16歳未満の子は所得税の扶養控除はありませんが、住民税のために用紙の下の欄に書きます。
  5. 異動月日及び事由今年の途中で結婚、出産、就職、離別などがあった場合は、ここに日付と理由を書きます。

ポイント この用紙は令和8年分です。
来年分(令和9年分)の用紙は、会社から別に配られます。

給与所得者の(特定増改築等)住宅借入金等特別控除申告書

誰が 住宅ローン控除の2年目以降の人添付 年末残高等証明書、控除証明書
  1. 1年目は確定申告住宅ローン控除を受ける最初の年は、会社員でも自分で確定申告をします。
    年末調整でできるのは2年目からです。
  2. 2年目以降の書類税務署から届く「住宅借入金等特別控除申告書」と「住宅ローン控除証明書」、金融機関から届く「年末残高等証明書」を会社に出します。
  3. 申告書の記入証明書に書かれた年末残高や控除額を、申告書の該当欄に写します。
    控除額は税額から直接引かれるので、結果が大きく変わります。

計算に使うには 控除証明書に書かれた「今年の控除額」を、下の自動計算の「住宅ローン控除額」に入れてください。

    よくある質問

    書類はいつまでに出しますか

    提出の締め切りは会社ごとに違います。
    多くの会社は11月ごろに集めます。
    令和8年分の改正は12月の年末調整でまとめて精算されます。

    毎月の給与の手取りはいつ変わりますか

    令和8年の1〜11月分の源泉徴収は改正前のままです。
    新しい源泉徴収税額表は、令和9年1月1日以後に払う給与から使います。

    年末調整をしてもらえない人はいますか

    年間の給与収入が2,000万円を超える人は対象外です。
    給与以外の所得が20万円を超える人や、医療費控除などを受けたい人は、年末調整のあとに確定申告をします。

    住民税の控除額も同じですか

    違います。
    住民税の控除額は所得税と別の制度で、金額や条件が違います。
    この計算は所得税の年末調整だけを対象にしています。

    計算結果は会社の結果と同じになりますか

    少しずれることがあります。
    年末調整では給与所得控除後の金額を国税庁の表で求めるため、数百円程度の差が出る場合があります。
    最終的な金額は会社の計算が正式です。

    この試算は令和8年度税制改正の内容をもとにした目安です。
    税理士による助言ではありません。
